


# Input shape
- example: "kn1b in e8"
  - "kn1b":
    - "kn" -> Knight
    - "1" -> first knight
    - "b" -> black color
- Alternative
  - Selection made by typing the nameId "kn1b"
  - Reachable cell are showed:
    - e8: "bi2w"
    - h1: "ki1w"

- Add(ChessMan, ChessCoor)
- Remove(ChessCoor)
